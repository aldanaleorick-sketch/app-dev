## 📘 Overview

**Avatar: The Last Airbender** is an American animated television series created by **Michael Dante DiMartino** and **Bryan Konietzko**, produced by **Nickelodeon Animation Studios**.  
The series follows **Aang**, the last surviving Airbender, on his journey to master all four elements and bring peace to the war-torn world.
